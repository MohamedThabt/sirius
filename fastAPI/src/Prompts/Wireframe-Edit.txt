Minimal generation rules for the LLM
Always produce a single JSON object for the wireframe root with type: "page".
Every node must include a unique id and a valid type.
Use children only for components where childrenAllowed is true.
Prefer specific field components (select, checkbox, radio-group, textarea, switch, datepicker) rather than overloading input, unless you intentionally want a generic text input.
For tables, prefer columns over legacy headers.
