## Project Goal
Create a modern, premium SaaS-style landing page for an AI-powered SDLC assistant tool with cutting-edge futuristic aesthetics, immersive animations, and developer-friendly design that captivates users through cinematic interactive experiences.

## Visual Style & Brand Identity
- **Typography**: Inter font family with light font weights and tight letter spacing for headings
- **Text Treatment**: Bold headings with semi-transparent body text for visual hierarchy
- **Icon System**: Phosphor icons with light weight consistently throughout
- **Color Palette**: Blues, violets, neons, and futuristic gradients with glowing elements
- **Design Philosophy**: Immersive, premium, tech-forward with cinematic quality and developer-friendly aesthetic
- **Visual Effects**: Soft shadows, glowing blur, floating visuals, and neon accents
- **Card Style**: Glassmorphic with blurred backgrounds and subtle transparency
- **Button Style**: Neumorphic with glowing hover effects and scale animations

## Cutting-Edge Technology Stack
- **GSAP**: Advanced animations, loading sequences, and scroll-triggered effects
- **Locomotive Scroll**: Smooth parallax scrolling and premium scroll experience
- **Spline 3D**: Interactive 3D elements integrated into hero sections
- **ScrollTrigger**: Scroll-based animation orchestration
- **Advanced Effects**: Floating elements, particle systems, and dynamic backgrounds

## GSAP Loading Animation & Progress Bar
Create a cinematic preloader experience:
- Fullscreen preloader with centered animated "SDLC AI Assistant" logo
- Modern progress bar filling 0% to 100% with smooth GSAP animation
- Loading completion sequence: progress bar fade → preloader scale/fade → main content reveal
- Tech-forward, smooth, premium loading experience that builds anticipation
- Animation example flow: "gsap.to('.progress-bar', { width: '100%', duration: 2, ease: 'power2.out' })"

## Advanced Animation & Interaction Strategy
- **GSAP Loading Sequence**: Cinematic preloader with progress bar and logo animation
- **GSAP ScrollTrigger**: Scroll-based animations for all sections with blur-to-clear, opacity 0→1, y: 40→0
- **Locomotive Scroll**: Smooth parallax scrolling and premium scroll experience
- **GSAP Timelines**: Chained animations using from(), fromTo(), stagger for orchestrated reveals
- **Page Load**: All content animates from 0 to 100% opacity while sliding up with blur effects
- **Floating Elements**: Background orbs and particles using GSAP yoyo & repeat animations
- **Hover Effects**: Cards lift and glow, buttons scale bounce, icons pulse with smooth transitions
- **Staggered Animations**: Elements appear in sequence with timing offsets for premium feel
- **Scroll Animations**: Sections animate in with opacity, blur, and position changes as user scrolls
- **Auto-draw Animations**: Diagrams and flowcharts draw themselves on scroll
